BoostHub - সম্পূর্ণ ভার্সন

GitHub এ বিল্ড:
1. নতুন রিপোজিটরি বানান, এই zip এর সব ফাইল (লুকানো .github ফোল্ডারসহ) আপলোড করুন।
2. Actions ট্যাব > Build APK > Run workflow।
3. শেষ হলে নিচের Artifacts থেকে BoostHub-APK ডাউনলোড করে ফোনে ইন্সটল করুন।

অ্যাপ সেটআপ: সেটিংস ট্যাবে ফেসবুক টোকেন, অ্যাড অ্যাকাউন্ট আইডি, পেজ আইডি, AI কী ও ব্যবসার তথ্য দিন।
প্রথমে অটোপাইলট "নিরাপদ মোডে" (সাজেশন) রেখে কয়েকদিন লগ দেখুন।
ব্যাটারি সেটিংসে BoostHub কে "Unrestricted" করুন, নইলে ফোন ব্যাকগ্রাউন্ড কাজ বন্ধ করে দেবে।
